# Kode Etik / Code of Conduct

Bahasa Indonesia di atas, English below.

## Bahasa Indonesia

Proyek ini kecil dan dikelola satu orang. Aturannya juga singkat:

1. Hormati orang lain. Kritik kode boleh sekeras apa pun, kritik orangnya tidak.
2. Tidak ada pelecehan, ujaran kebencian, doxxing, atau spam — di issue, PR,
   diskusi, maupun di channel WhatsApp yang memakai bot ini.
3. Laporan keamanan jangan di issue publik; ikuti [SECURITY.md](SECURITY.md).
4. Jangan pakai bot ini untuk spam WhatsApp. Melanggar ToS WhatsApp = nomor
   diblokir, dan itu risiko yang lo tanggung sendiri.

Pelanggaran dilaporkan lewat issue bertag `conduct` atau langsung ke pemilik
repo (@xykal). Keputusan akhir ada di pemilik repo: peringatan, lalu blokir.

## English

This is a small, single-maintainer project, so the rules are short:

1. Be respectful. Criticise code as hard as you like; do not attack people.
2. No harassment, hate speech, doxxing, or spam — in issues, PRs, discussions,
   or in WhatsApp channels that run this bot.
3. Do not file security reports as public issues; follow [SECURITY.md](SECURITY.md).
4. Do not use this bot to spam WhatsApp. Breaking WhatsApp's terms gets your
   number banned, and that risk is yours.

Report violations via an issue tagged `conduct` or directly to the repository
owner (@xykal). The owner has the final say: a warning first, then a block.
