## HIGH

**H1. CI `Code quality` merah 3 run berturut-turut.**
`.github/workflows/render-v4.yml:108`, `render-v5.yml:124`, `render-v6.yml:111` — step "Ringkasan"
pakai `$(basename $f)` dan `du -h $f` tanpa kutip. actionlint v1.7.12 (diunduh dari `main`, jadi
versinya ikut naik sendiri) melapor SC2086 dan exit 1. Badge README ikut merah sejak 87b5c68.
Fix: kutip `"$f"` di enam tempat. Diterapkan hari ini.

**H2. README bilang CLI dan APK pakai engine yang sama; kenyataannya sudah fork.**
`README.md:31` ("Keduanya pakai engine bot yang sama") vs `diff bot-js/src/wa.mjs cli/src/wa.mjs`
= 297 baris beda, `github.mjs` 34 baris, `format.mjs` 21 baris. Fix v1.6.5 (IPv4-first, retry) dan
penanganan code 515 ada di `bot-js`, tidak jelas ada di `cli`. Pengguna Termux dapat bug yang sudah
"fixed" di changelog. Fix: `cli/` impor modul dari `../bot-js/src` (npm workspace / `file:`), sisakan
`cli/src/bot.mjs` sebagai entry; atau ubah kalimat README jadi jujur ("CLI = versi ringan, fitur
terbatas") dan tulis tabel bedanya. Rekomendasi: opsi pertama, karena `channel.mjs`/`nomor.mjs`
sudah identik dan membuktikan modulnya portabel.

**H3. Aset pihak ketiga tanpa lisensi + media 39 MB di repo produk.**
`konten-tiktok/sfx/*.mp3` dan `sfxw/*.wav` (file yang sama dua format), stiker `stiker/*.webp`
(pack orang lain, diakui di `CARA-UPLOAD.md`), VO dan wav. Repo ini source-available dengan LICENSE
ketat, sementara isinya mendistribusikan ulang suara meme, ringtone, potongan suara tokoh publik.
Risiko: takedown DMCA ke repo produk, bukan cuma ke video; clone 75 MB (`.git` 35 MB) buat repo APK.
Render 180 menit di Actions untuk konten pemasaran juga area abu-abu kebijakan Actions ("unrelated
to the software project") — dengan riwayat akun yang pernah disuspend, ini risiko yang tidak perlu.
Fix: pindahkan `konten-tiktok/` + `render-v*.yml` ke repo terpisah (`xykal/konten-wa-release-bot`),
hapus dari sini, sekali `git filter-repo` supaya `.git` kempes; simpan hanya `CARA-UPLOAD.md` +
link. Aset sfx/stiker tetap tidak boleh di repo publik mana pun tanpa lisensi; ganti dengan SFX
CC0 (freesound filter CC0) atau bikin sendiri (section 23). Keputusan: kall.

## MED

**M1. Script remote tanpa pin.** `code-quality.yml:189` `bash <(curl .../actionlint/main/...)`.
Fix: unduh rilis spesifik + cek sha256, atau action yang di-pin SHA.

**M2. Semua action di-pin tag mayor (`@v7`), bukan SHA penuh** (7 workflow). Standar section 11.
Fix: resolve SHA via API per action, tulis `uses: owner/repo@<sha> # vX.Y.Z`, Dependabot sudah ada
jadi update SHA otomatis. Butuh 1 PR khusus, verifikasi di CI.

**M3. `bot-js/src/github.mjs:26` fetch tanpa timeout dan tanpa conditional request.**
Tanpa `AbortSignal.timeout`, satu cek bisa nyangkut sampai batas undici (menit). Tanpa
`If-None-Match`/ETag, tiap cek makan kuota 60/jam padahal 304 gratis dan 0 byte — cocok banget
dengan janji "0% data". Tambah header `X-GitHub-Api-Version: 2022-11-28`. Tes unit: mock 304.

**M4. `bot-js/src/bot.mjs:412` cek release cuma `lastTag === rel.tag`.**
Kalau maintainer hapus release terbaru, `/releases/latest` balik ke tag lama dan bot mengumumkan
"ADA RELEASE BARU! v1.5.0 -> v1.4.0". Fix: kalau dua-duanya semver valid dan `lte`, log "rollback,
dilewati" dan simpan tag baru tanpa posting. `semver` sudah jadi dependency.

**M5. Peluang posting dobel.** `bot.mjs:466-474` fallback ke `sendText` setelah `sendPertanyaan`
gagal — kalau gagalnya timeout ack (pesan sebenarnya masuk), channel dapat dua pesan.
`bot.mjs:484-489` `lastTag` disimpan setelah kirim; service dibunuh di celah itu = kirim ulang
siklus berikut. Fix: tulis `state.pending = {tag, attempt}` sebelum kirim; fallback hanya untuk
error non-timeout; attempt maksimal 3 lalu tampilkan tombol "kirim ulang" di app.

**M6. Worker lagu bisa dimatikan siapa saja.** `lagu/worker/worker.js:30,320` batas harian 80
itu global untuk semua pemasang APK. 80 request dari satu script = semua pengguna kena 429 sampai
besok. Fix: rate limit per IP di Cloudflare (rule gratis) + kuota per `install_id` di KV (header
dari app), global tetap sebagai pagar terakhir. Proving test: k6 di CI menembak endpoint staging.

**M7. `AndroidManifest.xml:19` `usesCleartextTraffic="true"`** — TODO terbuka dari audit lama.
Fix: `network_security_config.xml` yang cuma izinkan cleartext ke `127.0.0.1`; hapus atribut.

**M8. Atribusi XyVerse belum satu sumber dan belum pakai string resmi.**
`activity_main.xml:719-739` "BUILT IN" + logo, `contentDescription="XyVerse Tech"`;
`README.md:543` "Built in XyVerse"; `LICENSE:4` tanpa nama perusahaan; CLI tidak punya
`--version`; `bot-js/package.json` dan `cli/package.json` tanpa `author`. Standar section 12:
"Powered by XyVerse Technology Global", satu konstanta (`bot-js/src/config/brand.mjs` +
`res/values/brand.xml`), CLI `--version` mencetak `wa-release-bot <versi> — XyVerse Technology Global`.

**M9. i18n nol.** 77 `android:text` literal di layout vs 1 `@string`; `strings.xml` isinya 1 entri;
~179 string literal di `MainActivity.kt`. README dan changelog Indonesia saja. Untuk audiens GitHub
global (dan TikTok yang bisa nyasar ke luar), minimal: pindah ke `strings.xml` (Android Lint
`HardcodedText` sudah bisa nangkap), README bagian English ringkas di atas.

**M10. Modul kegemukan.** `MainActivity.kt` 1263 baris, `bot.mjs` 1080, `HostingActivity.kt` 519,
`BotService.kt` 506 (batas ~250). Fix bertahap: `bot.mjs` pecah jadi `jadwal.mjs`, `rilis.mjs`,
`perintah.mjs`; `MainActivity` pecah per kartu UI. Tidak ubah perilaku, dites lewat unit test yang ada.
