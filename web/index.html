Kenal sama yang ini?

Grup kemasukan akun spam jam dua pagi

Penjaga grup nyaring permintaan gabung satu-satu. Yang dulu udah keluar atau pernah dikeluarin, ditolak otomatis.

Channel sepi kayak kuburan

Tiap hari bot ngirim potongan lagu 60 detik sebagai voice note, lengkap dengan caption yang dibikin AI.

Rilis aplikasi lupa diumumin

Begitu ada tag baru di GitHub, bot posting: apa yang baru, file yang bisa diunduh, sampai ukurannya.

Fitur

Semua bisa diatur dari layar app. Nggak ada file config yang harus diedit.

Rilis ke channel

Cek release tiap 15 menit (bisa diubah), pakai ETag jadi repo yang belum berubah nggak makan kuota API. Multi repo, tiap repo baseline sendiri.

Penjaga grup

Auto-approve permintaan gabung, tolak yang pernah keluar atau dikeluarin, daftar hitam manual.

Lagu mood harian

148 lagu plus yang lagi tren, dikirim sebagai voice note dengan caption 11 gaya: galau, motivasi, ayat, sampai nyindir.

Hosting bot custom

Punya bot Node.js kecil sendiri? Unggah ZIP-nya, jalan di dalam app yang sama.

Notifikasi kalau gagal

Kirim gagal tiga kali berturut-turut: notifikasi Android plus laporan ke chat kamu sendiri. Nggak ada yang hilang diam-diam.

Tautkan sekali seumur hidup

Pairing code 8 huruf tanpa HP kedua, atau QR. Sesi disimpan terenkripsi di HP.

Kok bisa tanpa server?

Yang dipakai di dalam APK, apa adanya.

  1. KotlinService Android di foreground, watchdog WorkManager, dan boot receiver. Kalau Android bunuh service-nya, dia nyala lagi.
  2. Node.js 18 (nodejs-mobile)Engine bot ditulis JavaScript dan jalan di Node beneran di dalam APK. Kode yang sama dipakai versi CLI buat Termux/PC.
  3. BaileysProtokol WhatsApp Web multi-device. Nyambung cuma beberapa detik waktu posting, sisanya tidur.
  4. Cloudflare Worker + AICaption lagu dibikin di Worker (model Groq) dengan batas harian per perangkat. Token AI nggak pernah ada di HP.

Satu siklus, 15 menit

  1. Bangun
  2. Cek rilis GitHub
  3. Cek permintaan gabung
  4. Kirim lagu harian (kalau jadwalnya)
  5. Tidur lagi

Privasi dan keamanan

Botnya di HP kamu, datanya juga.

Nggak ada server tengah

HP kamu ngobrol langsung ke GitHub dan WhatsApp. Nggak ada akun, nggak ada dashboard, nggak ada pihak ketiga yang lihat pesan.

Token tetap di HP

Token GitHub (opsional, buat repo privat) dan sesi WA disimpan di penyimpanan privat app.

Kode bisa dilihat

Source-available di GitHub: CI publik, CodeQL, audit dependensi, APK dibangun otomatis dari tag dengan checksum SHA-256.

Lisensi pemakaian pribadi

Boleh dipakai dan dipelajari. Nggak boleh dijual atau disebar ulang tanpa izin.

Pertanyaan yang sering muncul

Perlu root atau Termux?

Nggak dua-duanya. Pasang APK, tautkan WA, isi repo dan channel, tekan Mulai.

HP-nya harus nyala terus?

Iya, ini bot yang jalan dari HP. Paling cocok buat HP nganggur yang dicolok charger. Konsumsi baterainya kecil karena WA cuma nyambung waktu ada yang mau dikirim.

Nomor WA-nya kena banned nggak?

Bot cuma ngirim ke channel atau grup milik kamu sendiri, dengan jeda wajar, bukan broadcast ke orang. Tetap pakai nomor khusus bot kalau mau lebih aman.

Bisa lebih dari satu repo?

Bisa. Isi kolom repo pakai koma, tiap repo dicek dan diumumkan terpisah.

Repo privat?

Bisa, isi token GitHub dengan scope repo di setelan. Tokennya nggak pernah keluar dari HP.

Android versi berapa?

Android 8.0 (API 26) ke atas, arm64 atau armeabi-v7a. Ada APK universal kalau nggak yakin.
